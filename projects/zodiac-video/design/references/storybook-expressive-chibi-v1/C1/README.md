# C1 reference-only files

Copied from the approved C1 finalist demo in the app repository for visual review and design-system grounding.

These SVGs are illustrative references, not production assets. Their paths are under design/references rather than assets/, and they must not be exposed through Writer Context allowed_assets. They are not frozen: production masters can be redrawn or refined if they follow the approved Storybook Expressive Chibi v1 specification.

Contents:
- characters/: four identity silhouette references;
- expressions/: the 11 baseline face acting references;
- camera/: six independently authored C1 demo compositions.

Canonical rules live in ../../storybook-expressive-chibi-v1.md. The C1 source in the application repo remains in demo/style-finalist/C1/ for comparison.
